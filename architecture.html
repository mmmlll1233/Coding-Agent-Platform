sequenceDiagram actor User participant UI as TUI / Remote / Pipe participant Agent as Agent 主循环 participant Client as LLM Client participant Tool as 工具注册表 participant Perm as 权限系统 participant Ctx as 上下文管理 User->>UI: 输入消息 UI->>Agent: conversation.add_user_message() Note over Agent: 注入环境上下文 + 长期记忆 Agent->>Ctx: 检查上下文窗口 Ctx-->>Agent: 可能触发 L1/L2 压缩 Agent->>Agent: 构建系统提示词 loop 每个 turn Agent->>Client: stream(conversation, system, tools) Client-->>Agent: TextDelta / ThinkingDelta / ToolCallComplete / StreamEnd alt 无工具调用 Agent->>UI: StreamText → LoopComplete else 有工具调用 loop 每个工具 Agent->>Perm: 权限检查 Perm-->>Agent: deny / ask / allow alt ask (需要用户确认) Agent->>UI: PermissionRequest UI-->>Agent: PermissionResponse end Agent->>Tool: execute(params) Tool-->>Agent: ToolResult Agent->>UI: ToolResultEvent end Agent->>UI: TurnComplete end end Agent->>Agent: 记忆提取 (每5轮) Agent->>UI: LoopComplete UI-->>User: 显示回复
